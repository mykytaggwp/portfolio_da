# 🛒 E-commerce Sales & User Traffic Analytics

Аналітичний проєкт із дослідження продажів інтернет-магазину, ефективності каналів залучення трафіку та поведінки користувачів. 

Пайплайн проєкту охоплює повний цикл роботи з даними: вивантаження даних із Google BigQuery (SQL), аналіз та первинне оброблення у Python (Jupyter Notebook), та побудову інтерактивного двосторінкового дашборду в Tableau Public.

## 💡 Основні висновки та інсайти (Key Insights)

### 1. Продажі та Категорії Товарів (Sales & Category Insights)
* Топ-категорії: Категорії Sofas & Armchairs ($1,685,122) та Chairs ($1,057,429) є основними драйверами виручки, сумарно забезпечуючи понад 45% всього виторгу.
* Географія: США лідирують за обсягом продажів ($2.5M+), за ними йдуть Індія та Канада.

### 2. Аналіз трафіку та пристроїв (Traffic & Device Analysis)
* Джерела трафіку: Organic Search (21,297 сесій) та Paid Search (16,151 сесій) генерують понад 60% всього веб-трафіку магазину.
* Пристрої: Користувачі Desktop забезпечують найбільшу суму продажів ($3.44M) порівняно з Mobile ($2.26M), що вказує на вищу конверсію на десктопних версіях.
* Лояльність: Більша частина активних користувачів (3,677) мають підтверджений статус Email-підписки, що є потенціалом для регулярних CRM-розсилок.
