# 🛒 E-commerce Sales & User Traffic Analytics

Аналітичний проєкт із дослідження продажів інтернет-магазину, ефективності каналів залучення трафіку та поведінки користувачів. 

Пайплайн проєкту охоплює повний цикл роботи з даними: вивантаження даних із Google BigQuery (SQL), аналіз та первинне оброблення у Python (Jupyter Notebook), та побудову інтерактивного двосторінкового дашборду в Tableau Public.

## 💡 Основні висновки та інсайти (Key Insights)

### 1. Продажі та Категорії Товарів (Sales & Category Insights)
* Топ-категорії: Категорії Sofas & Armchairs ($8.39M) та Chairs ($6.15M) є основними драйверами виручки, сумарно забезпечуючи понад 45% всього виторгу.
* Географія: США безумовно лідирують за обсягом продажів ($13.94M), за ними з великим відривом йдуть Індія ($2.81M) та Канада ($2.44M).

### 2. Аналіз трафіку та пристроїв (Traffic & Device Analysis)
* Джерела трафіку: Organic Search (124,425 сесій) та Paid Search (94,341 сесій) генерують основну частку всього веб-трафіку магазину.
* Пристрої: Користувачі Desktop забезпечують найбільшу суму продажів ($18.86M) порівняно з Mobile ($12.38M) та Tablet ($0.72M), що вказує на вищу конверсію на десктопних версіях.
* Лояльність: Більша частина зареєстрованих користувачів (20,036 з 27,945, або ~71.7%) мають підтверджений статус Email-підписки, що є потенціалом для регулярних CRM-розсилок.

## 📑 Структура Дашборду у Tableau
Дашборд складається з 2-х інтерактивних сторінок (Tabs):
1. Executive Overview Dashboard:
   * Картки KPI (Sales, Sessions, Orders, AOV).
   * Графік щоденної динаміки продажів (Sales Trend).
   * Топ-10 категорій товарів та Топ-5 країн.
2. User & Traffic Dashboard:
   * Розподіл сесій за джерелами трафіку (Sessions by Channel).
   * Обсяг продажів за типами пристроїв (Sales by Device).
   * Статус підтвердження пошти користувачів (Email Status).
